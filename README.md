# Apple Homepage Clone — Bootstrap Edition

Responsive Apple-style homepage recreation built with:

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap 5.3.3 (CDN)

Bootstrap is used for the responsive container system, grid, spacing, breakpoints and responsive navigation visibility. Custom CSS preserves the Apple-style visual treatment.

## Run

Open `index.html` in a browser. An internet connection is required for Bootstrap CDN and official Apple image assets.
